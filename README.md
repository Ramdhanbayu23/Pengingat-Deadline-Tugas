# Teman Deadline

Teman Deadline adalah web sederhana yang saya buat untuk membantu mengingat deadline tugas kuliah. Saya bisa menambahkan nama tugas, mata kuliah, dan tanggal pengumpulannya. Tugas juga bisa ditandai selesai atau dihapus.

Saya menggunakan HTML untuk menyusun halaman, CSS untuk mengatur tampilannya, dan JavaScript untuk mengelola daftar tugas. Data tugas disimpan di browser, jadi tetap ada saat halaman dibuka kembali.

Untuk mencoba web ini, buka file `index.html` di browser.
